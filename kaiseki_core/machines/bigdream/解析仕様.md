## ★ 機種汎用化の鉄則 (最重要)
- **「有利区間は差枚2400枚で完走」はほぼ全スマスロ共通**。
- だが **信号の上がり方・連荘の仕方・切断契機は機種ごとに全然違う**。
- 新機種追加時は、まず次の3点を機種ごとに確定してから adapter を書く:
  1. **切断契機** (何で有利区間が切れるか: 上位AT終了 / 天国終了 / 規定G完走 など)
  2. **信号の意味** (どの種別が CZ / AT / 上位 か)
  3. **連荘の継続条件** (どこまでを1連荘とするか)
- ビッグドリームのロジックを別機種にそのままコピーしない。

## 1. 基礎用語

### 有利区間
- 【意味】 出玉管理区間。**差枚2400枚で必ず完走 (切断/リセット)**。
- 【解析】 切断点で差枚カウンタをリセット。連荘・初当たり・期待値の集計単位の土台。
- 【実装】 `Yuri_Diff_Pre` 列。ビッグドリームでは **上位AT発動でリセット**。
- 連荘 ≠ 有利区間 (連荘はCZ/直撃で切れる、有利区間は上位AT切断/2400完走で切れる。1有利区間に複数連荘)。

### 有利区間差枚
- 【意味】 有利区間に入ってからの累積差枚。2400で完走。
- 【計算】 行ごと delta = `Dedama - Start×1.629`。累積した値。
- 【実装】 `Yuri_Diff_Pre` = その当たり発生**直前**の累積差枚 (state.py 時系列計算)。
- 【上位ATとの関係】 差枚 **2300枚** 到達後、AT終わりの 5-25G が **上位AT** になる (完走2400手前で上位引き上げ)。2300未到達なら 5-25G でも上位にならない。

### 純増 / コイン持ち / 純減
- 【意味】 純増=AT中1Gあたり増える枚数 (8.2枚/G)。コイン持ち=通常時50枚で回せるG数 (30.7G)。純減=通常時1Gあたり減る枚数。
- 【実装】 `INVEST_PER_G = 50/30.7 ≈ 1.629枚/G` (純減レート、投資計算の基礎)。

### TY (Total Yield)
- 【意味】 1連荘で取れた総出玉。
- 【実装】 `net_payout` = `raw_payout` = 連荘内AT行のDedama合計。仮想ヤメ等は入れない (連荘境界はChain_IDで表現済)。

### 機械割
- 【意味】 投資に対する回収率。100%超で勝てる。
- 【実装】 `100 + 累積EV / 期待総投資 × 100`。期待総投資 = (Nから平均消化G + 累積TY/AT純増) × 3枚掛け。

### 初当たり (AT初当たり)
- 【意味】 CZ経由 or 直撃で AT に突入すること。引き戻し(再当選)は含めない。
- 【計算】 `pre_normal_g` = 前のAT終了(or着席)からこの連荘のAT当選まで回した通常G。
- 【表現1】 平均初当たりG = ビン内 chain の pre_normal_g 平均。
- 【表現2】 区間当選率 (天井狙い表) = 離散ハザード = COUNTIFS(pre_normal_g∈[N,N+5)) ÷ COUNTIFS(pre_normal_g≥N)。
- 【フィルタ】 全シートで `first_state ≠ 引き戻し` で引き戻しを初当たりから除外。

## 2. 状態 (State) — ビッグドリーム判定 (state.py)

| 状態 | 判定条件 |
|---|---|
| CZ成功 | RB行で、次AT が Start≤3 |
| CZ失敗 | RB行で、次が AT でない or Start>3 |
| 下位AT | 直前=RB かつ Start≤3 (CZ成功) / 連荘継続中の通常AT |
| 上位AT | 下位連荘で純増≥1000枚 or 有利区間差枚≥2300枚 到達後、Start 5-25G で発動 |
| 引き戻し | 直前=AT かつ Start 26-80G |
| 直撃 | 直前=AT かつ Start>80 / prev=RBでStart>3 |
| 朝一直撃 | 台日で最初のAT |

### 上位AT 補足
- **3000枚確定**: 下位純増≥3000で発動した上位は 500枚格下げ免除。
- **500枚格下げ**: 上位AT連続行のDedama合計<500枚なら引き戻しに格下げ。

### 直撃の重要ポイント (誤解注意)
- 直撃は **新しい有利区間ではない**。直撃で有利区間差枚はリセットされず累積継続 (データ: 直撃行YDPが0の割合0.1%、平均-1170枚)。
- 直撃が区切るのは **連荘(Chain_ID)** と **累積G表示カウンタ(cycle_g)** だけ。
- 直撃→下位連荘が1000枚未満で終われば切断してない (有利区間継続)。1000枚(or差枚2300)到達→5-25Gで上位発展して初めて切断。

### 切断
- 上位AT発動 = 有利区間リセット = 切断。yuri_diff のリセット契機はこれのみ。

## 3. 連荘・集計の概念

### 連荘 (chain) — `Chain_ID`
- 【新連荘起点】 ①朝一初AT ②直前=RB(CZ介在) ③Start>80(直撃)
- 【継続】 直前=AT かつ Start≤80 (= Start0-4継続 / 上位AT / 引き戻し を1連荘に同居)
- 【値】 chain_length / raw_payout(=TY) / first_state / pre_normal_g

### 累積G
- 前回通常累積G `cycle_g_pre` = 通常Gのみ累積
- 直前有利区間G `cycle_total_g_pre` = 通常G + AT中G累積 (AT中G平均194G/最大1832Gと大きいのでビン移動が起きる)
- リセット契機: 上位AT終了 / 直撃 (表示カウンタのみ)

### 朝N回目 / 切断後N回目
- 朝N回目 `chain_number_morning` (台日連番) / 集計用 `chain_number_morning_safe` (切断・直撃以降はNaN=除外)
- 切断後N回目 `chain_number_cut` (上位AT終了でリセット)

## 4. 解析シート一覧
- AT間天井狙い — 打ち始めG別の期待値 (5G刻み)
- 回数別AT間 (朝/切断後) — N回目別
- 累積G別AT間 — 前回通常G / 直前有利区間G 別
- 直前有利区間G別期待値 — 8ブロック×5G刻み
- 直撃分布 — 累積G別の直撃当選率
- 引き戻し分布 — 戻し判定用一撃枚数別 (下位AT区間のみ表示)

## 5. 調査済みメモ

### 2400完走の扱い (2026-05-20)
- 実機: 連荘中に有利区間差枚2400超えで必ずエンディング→上位AT移行 (5-25Gで上位)。
- 実装に明示「2400完走リセット」は無いが、既存の上位AT判定 (yuri_diff≥2300 アンロック→次5-25G→上位→リセット) で **97.3% 自動捕捉**。
- 調査: 2400超え372回中、上位解決362(97.3%)、リセット漏れ5件(1.3%)、未解決5件。
- 結論: **明示ロジック不要 (A案)**。1.3%は無視範囲。

### TY定義 (2026-05-20)
- 一時「即やめ+25G試行」仕様を入れたが撤回。`net_payout = raw_payout` (1連荘総出玉) に確定。
- 仮想ヤメは TY に混ぜず、連荘境界(Chain_ID)に任せる。
